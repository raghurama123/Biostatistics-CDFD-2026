1. One-sample z-test

Use this test when the population standard deviation $\sigma$ is known.

$$H_0:\mu=\mu_0$$ $$\boxed{z=\frac{\bar X-\mu_0}{\sigma/\sqrt n}}$$
Enter the null mean $\mu_0$, observed sample mean $\bar X$, known population standard deviation $\sigma$, and sample size $n$. If $X$ is a single observation rather than a sample mean, set $n=1$.

3. Alpha, beta, and statistical power

$$P(\text{Type I error}\mid H_0)=\alpha,\qquad P(\text{correctly do not reject }H_0\mid H_0)=1-\alpha$$ $$P(\text{Type II error}\mid H_1)=\beta,\qquad P(\text{correctly reject }H_0\mid H_1)=1-\beta$$ $$\boxed{\text{Power}=1-\beta}$$
This simulator uses a standardized effect size $d$. Under $H_1$, the z-statistic distribution is shifted by $$\lambda=d\sqrt n.$$

Reducing Type I error: use a smaller $\alpha$, correct for multiple testing when appropriate, and pre-specify hypotheses and analysis decisions.

Reducing Type II error: increase $n$, reduce measurement variability, and use an efficient design.

Trade-off: for fixed $n$ and effect size, lowering $\alpha$ usually increases $\beta$. Increasing $n$ can recover power while keeping $\alpha$ small.

4. Sample size for a fixed confidence interval

For a confidence interval for a population mean with known $\sigma$:

$$\bar X\pm z_{1-\alpha/2}\frac{\sigma}{\sqrt n}$$

If the desired margin of error is $E$:

$$E=z_{1-\alpha/2}\frac{\sigma}{\sqrt n}$$ $$\boxed{n=\left(\frac{z_{1-\alpha/2}\sigma}{E}\right)^2}$$
Always round $n$ up. If the desired total interval width is $W$, then $E=W/2$.
