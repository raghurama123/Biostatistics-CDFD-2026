Beta and Statistical Power

Type II error and power

Suppose we test a population mean using a normal test statistic. Under the null hypothesis,

$$ Z \sim N(0,1). $$

If the alternative hypothesis is true, the distribution of the test statistic is shifted away from zero.

A Type II error occurs when $H_1$ is actually true but we do not reject $H_0$.

$$ \beta = P(\text{do not reject }H_0 \mid H_1\text{ is true}) $$

Statistical power is the probability of correctly rejecting $H_0$ when $H_1$ is true:

$$ \boxed{ \text{Power}=1-\beta } $$
This simulator uses a standardized effect size $d$. For a sample size $n$, the alternative distribution is shifted by $$ \lambda=d\sqrt{n}. $$ Larger effects and larger sample sizes generally increase power.

Interpretation:

$\alpha$ controls the Type I error rate when $H_0$ is true.

$\beta$ is the probability of a Type II error when $H_1$ is true.

$1-\beta$ is the statistical power of the test.

How can we reduce Type I and Type II errors?

To reduce Type I error (false positive):
  • Use a smaller significance level $\alpha$.
  • Correct for multiple testing when many hypotheses are tested.
  • Pre-specify the hypotheses, test direction, and analysis rather than changing them after seeing the data.
To reduce Type II error (false negative) and increase power:
  • Increase the sample size $n$.
  • Reduce measurement error and other unnecessary variability.
  • Use an efficient study design that extracts more information from the same number of observations.
  • Use a one-tailed test only when a directional alternative is scientifically justified and specified in advance.
What the sliders demonstrate:
  • Increasing $n$ separates the $H_0$ and $H_1$ distributions, decreases $\beta$, and increases power.
  • A larger true effect size also separates the distributions and increases power. The true effect size is usually not a quantity the investigator can simply choose.
  • Increasing $\alpha$ increases power but also increases the Type I error rate.
  • Decreasing $\alpha$ reduces Type I error but, for fixed $n$ and effect size, usually increases $\beta$.
Key trade-off: $$ \alpha \downarrow \quad\Rightarrow\quad \beta \uparrow \quad\Rightarrow\quad \text{power} \downarrow $$

if sample size and effect size are unchanged. Increasing the sample size can recover power while keeping a stringent significance level.
